# TripVerse README media

This folder contains 29 optimized images used by the repository's visual product showcase:

- `screens/`: nine current application captures, including home, both travel journals, the destination and chapter galleries, desktop Explore, its mood chapter and index, and the phone journal.
- `mockups/`: all ten existing TripVerse application mockup compositions.
- `artwork/`: all ten existing TripVerse campaign compositions.

Screenshot captures preserve the real application UI. The mockups and campaign images are presentation artwork and are labeled separately in the main README. Additional Trip Studio screenshots are referenced directly from the existing `frontend/public/guide/` collection.

Images are kept outside the application public folder so this documentation gallery does not add media to the frontend build. High-resolution originals remain in the local TripVerse design collections; these copies preserve their proportions and colors at sizes suitable for GitHub.

Third-party photographs, fonts, and illustrations retain their own licenses and attribution requirements. See the main README's Credits and MIT license sections.
